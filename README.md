# Mabrook Gas Centre Android App

Free Android app for preparing trilingual WhatsApp stock announcements.

## Build online
1. Create a **public** GitHub repository called `MabrookGasCentre`.
2. Upload **all files and folders** from this ZIP into the repository root, preserving `.github/workflows/build-apk.yml`.
3. Go to **Actions** > **Build Android APK** > **Run workflow**.
4. Open the successful run, download **MabrookGasCentre-APK** from **Artifacts**.
5. Unzip the downloaded artifact to obtain `app-debug.apk`.
6. Transfer to Android phone and open the APK. Allow installation from that source if prompted.

WhatsApp sharing requires selecting a chat and tapping Send. This is intentional.
